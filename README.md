# Product Tracker — Full Stack App

A simple full-stack product inventory tracker built while learning REST APIs.

## Tech Stack
- **Backend:** FastAPI (Python) + SQLAlchemy
- **Database:** MySQL
- **Frontend:** React + Axios
- **API testing:** Swagger UI (auto-generated by FastAPI) + Postman

## Features
- View all products
- Add a new product
- Edit an existing product
- Delete a product
- Data persists in a MySQL database

## Running Locally

**Backend:**
```bash
cd fast_api_demo_recording
source myenv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
Runs at `http://127.0.0.1:8000` — docs at `/docs`

**Frontend:**
```bash
cd frontend
npm install
npm start
```
Runs at `http://localhost:3000`
